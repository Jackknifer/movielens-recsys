# movielens-recsys

## 模型

- 召回：YoutubeDNN 双塔，结合物品相似、类型兴趣和热门召回。
- 排序：DCNv2。
- 合并与重排：Snake Merge 合并候选，连续相同类型或年代最多展示 2 部电影。

## 数据集

MovieLens-1M：6,040 位用户、3,883 部电影、1,000,209 条评分。
采用 FunRec 数据表，评分统一为 1～5 分，4 分及以上为正样本。
每位用户按时间保留最后两条交互，分别用于验证和测试。
训练集 988,129 条，验证集和测试集各 6,040 条。

## 实验配置

| 项目 | 配置 |
| --- | --- |
| 环境 | Python 3.11、TensorFlow 2.15。 |
| 特征 | 9 个类别特征、22 个数值特征；Embedding 维度 16，历史长度 10。 |
| 召回训练 | Sampled Softmax，采样数量 20，温度 0.1，训练 3 轮。 |
| 排序结构 | 3 层 Cross Network，DNN 为 [64, 32]，Dropout 为 0.1，L2 为 0.000001。 |
| 排序样本 | 每位用户的训练交互中，前 80% 提供历史，其余构成目标窗口。 |
| 优化参数 | Adam，学习率 0.001；召回每批 128 条样本，排序每批 32 位用户。 |
| 排序训练 | 列表级 Softmax 损失，最多 10 轮；连续 3 轮指标未改善时终止训练。 |

配置见 [offline.yaml](config/offline.yaml)，模型按验证集 NDCG@20 选择。

## 实验结果

2026-10-25 的固定候选实验使用 5,435 位用户的 543,500 条排序训练样本。
每位用户固定 100 个候选，评估前 20 个结果。
测试指标统计 3,563 位高评分目标用户，仅使用训练历史。
排序随机种子为 42、2025、2026，以下为均值与标准差。

| 阶段 | Recall@20 | NDCG@20 |
| --- | --- | --- |
| DCNv2 排序 | 19.665% ± 0.422% | 0.08111 ± 0.00165 |
| 类型与年代重排 | 19.319% ± 0.242% | 0.07939 ± 0.00144 |
